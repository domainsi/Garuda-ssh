## 📌 Tentang GARUDA SSH

**GARUDA SSH** adalah kerangka kerja (*framework*) audit keamanan otonom dan intelijen ancaman siber (*Cyber Threat Intelligence / CTI*) tingkat lanjut yang dirancang khusus untuk ekosistem **Kali Linux**, distribusi Linux, serta **Termux (Android)**.

Tool ini mengintegrasikan **52 Modul Analisis Otonom**, menggabungkan pengintaian aktif/pasif, mining parameter dinamis berbasis kecerdasan buatan (*Generative AI Synthesizer*), verifikasi pertahanan WAF, hingga pengujian bukti konsep struktural (*Real-Time Live Deface PoC Probing*) yang disertai validasi rantai bukti forensik (*Forensic Chain of Custody*) berstandar hash **SHA-512**.

### ⚡ Keunggulan Utama
- 🚀 **Zero External Dependencies**: 100% dibangun menggunakan pustaka standar Python (*Python Standard Library*). Anda tidak perlu repot melakukan instalasi dependensi pip yang rumit!
- 🛡️ **52 Modul Otonom Terpadu**: Dari BGP ASN, DoH DNS, GEOINT, SSL/TLS Ciphers, crt.sh Subdomains, hingga analisis integritas DOM.
- 🤖 **Dynamic Parameter Miner & AI Synthesizer**: Menambang parameter web secara otonom dan memvalidasi respons server.
- 🎯 **Real-Time Live Deface PoC Probing**: Menguji kerentanan struktural server target dan menyertakan rekomendasi mitigasi (*Server-Side Integrity Protections*).
- 📜 **Forensic Chain of Custody (SHA-512)**: Setiap hasil modul diekspor ke direktori `evidence/` dengan manifest verifikasi kriptografi integritas data.

## 🚀 Panduan Instalasi (Mudah & Cepat)

Pilih salah satu cara instalasi di bawah ini sesuai dengan lingkungan yang Anda gunakan:

### 🔹 Opsi 1: Instalasi Otomatis (Kali Linux / Linux / Termux)

Cukup clone repositori lalu jalankan installer otomatis:

```bash
# 1. Clone repositori dari GitHub
git clone https://github.com/domainsi/Garuda-ssh

# 2. Masuk ke direktori proyek
cd garuda-ssh

# 3. Berikan izin eksekusi pada installer dan jalankan
chmod +x install.sh
./install.sh
```

---

### 🔹 Opsi 2: Instalasi Manual di Kali Linux / Ubuntu / Debian

Jika Anda ingin melakukan konfigurasi manual langkah demi langkah:

```bash
# 1. Update sistem dan pastikan python3 terpasang
sudo apt update && sudo apt install -y python3 git

# 2. Clone repositori
git clone https://github.com/domainsi/Garuda-ssh
cd garuda-ssh

# 3. Berikan izin eksekusi pada skrip utama
chmod +x garuda_ssh.py

# 4. Siapkan folder bukti forensik
mkdir -p evidence
```

---

### 🔹 Opsi 3: Instalasi di Termux (Android)

Untuk pengguna Android yang menjalankan Termux:

```bash
# 1. Update paket Termux dan pasang python serta git
pkg update -y && pkg install -y python git

# 2. Clone repositori
git clone https://github.com/domainsi/Garuda-ssh
cd garuda-ssh

# 3. Berikan izin eksekusi
chmod +x garuda_ssh.py

# 4. Buat folder bukti
mkdir -p evidence
```

## 🎯 Cara Penggunaan (Usage)

Menjalankan GARUDA SSH sangat mudah dan intuitif.

### 1. Menjalankan Pemindaian pada Domain Target
Gunakan skrip utama `garuda_ssh.py` dengan memasukkan domain target:

```bash
python3 garuda_ssh.py example.com
```

> **Catatan:** Argumen domain target wajib diisi. Program akan menampilkan peringatan jika dijalankan tanpa target.

---

### 2. Memeriksa Bukti Forensik & Telemetri
Setelah proses pemindaian 52 modul selesai, seluruh output telemetri tersimpan rapi dalam folder `evidence/`:

```bash
# Melihat daftar file log modul hasil scan
ls -la evidence/

# Memeriksa manifes integritas rantai bukti (Chain of Custody SHA-512)
cat evidence/chain_of_custody.sha256
```
